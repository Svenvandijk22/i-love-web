1. Variables = let en const

Variabelen gebruik je om data op te slaan. Met let kun je een waarde later veranderen. Met const blijft de waarde hetzelfde en kun je deze niet opnieuw aanpassen. Daarom gebruik je const als iets niet hoeft te veranderen en let als de waarde later nog aangepast moet worden.

let naam = "Sven";
    const naam = "Sven";

Resultaat

Variabelen kunnen verschillende soorten data opslaan zoals strings, numbers en booleans.

2. Functions

Functions zijn herbruikbare blokken code. Ze helpen om structuur te houden.

function begroet(naam) {
  return "Hallo " + naam;
}

console.log(begroet("Sven"));

Mijn notities

Een function wordt pas uitgevoerd wanneer je hem aanroept.
